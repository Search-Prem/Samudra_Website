Module 1

Samudra Nauka

Nauka INPUT PROCESS OUTPUT
Samudra NaukaModule animation preview

What this module does

Samudra Nauka is an AI-driven naval CAD module designed for parametric hull generation and rapid geometry modeling. Built with an integrated AI agent, it allows engineers to modify hull parameters, surface curvature, and principal dimensions using plain natural language commands.

Supports automated surface fitting, line plan generation, and seamless IGES/STL export directly into downstream stability, structural, and CFD solver pipelines.

Module 2

Samudra Sthira

Sthira INPUT PROCESS OUTPUT
Samudra SthiraModule animation preview

What this module does

Samudra Sthira automates hydrostatic calculations and intact or damage stability assessments for naval vessels. By prompting the AI agent, users can evaluate displacement, longitudinal center of buoyancy (LCB), metacentric height (GM), and GZ cross curves instantly.

Generates regulatory-ready stability booklets, tank capacity tables, and loading conditions with automated compliance checks against naval architectural standards.

Module 3

Samudra Sanrachna

Sanrachna INPUT PROCESS OUTPUT
Samudra SanrachnaModule animation preview

What this module does

Samudra Sanrachna provides AI-powered finite element analysis (FEA) and structural integrity evaluation for ship hulls. It translates natural language prompts into structural meshing, load case assignments, and stress distribution analyses across midship sections and bulkheads.

Calculates von Mises stress contours, global hull girder bending moments, and local plate buckling safety factors to accelerate structural optimization.

Module 4

Samudra Vega

Vega INPUT PROCESS OUTPUT
Samudra VegaModule animation preview

What this module does

Samudra Vega is an AI-assisted CFD simulation visualizer engineered for hydrodynamic flow, wave resistance, and pressure field analysis. It streamlines domain meshing, boundary condition setup, and solver execution directly through natural conversational commands.

Renders interactive 3D velocity vectors, wall pressure heatmaps, and turbulent wake streamlines around the hull.
